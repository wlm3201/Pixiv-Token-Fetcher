# Pixiv Token Fetcher

一键完成 Pixiv 的 Oauth 获取 Refresh Token 和 Access Token 令牌

## 安装说明

- 下载[扩展](https://github.com/wlm3201/Pixiv-Token-Fetcher/releases/download/release/Pixiv-Token-Fetcher-v1.0.0.zip)
- 打开 [chrome://extensions/](chrome://extensions)
- 右上角打开 "开发者模式"
- 拖入扩展

## 使用说明

- 打开 pixiv[https://www.pixiv.net]并登陆
- 右上角点开此扩展
